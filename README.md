## Notes

- **Carousel slides are one post.** Select all of `cabo-01…08` in order — that is a single 8-slide upload, not eight posts. Same for `3-decisions-01…03` and `app-vs-advisor-01…05`.
- **`CLIENT-POV-do-not-post-to-FB.png` is not for Bonnie's feed.** It's written in "our advisor" for the traveller to post. Never goes on Bonnie's own Facebook.
- **Stories have no captions** — the frame is the content.
- **`buffer-import.csv`** carries relative labels (`Week 3 Wed`). Set a start date in `review.html`'s Ship It dialog to export real dates instead.
- Every reel ships with a `-NOAUDIO` cut so it can be rescored with a trending track without a rebuild.
