## Notes

- **`02-the-walk.mp4` is one unbroken take** — the room door down to the water, no cuts, one
  line at the end. Post it as-is; it does not need trimming.
- **Carousel slides are one post.** Select all of `cabo-01…08` in order — a single 8-slide
  upload, not eight posts. Same for `3-decisions-01…03` and `app-vs-advisor-01…05`.
- **`CLIENT-POV-do-not-post-to-FB.png` is not for Bonnie's feed.** It's written in "our advisor"
  for the traveller to post. Never goes on Bonnie's own Facebook.
- **Stories have no captions** — the frame is the content.
- Every reel ships with a `-NOAUDIO` cut for a trending audio track.
- **`buffer-import.csv`** uses relative labels (`Week 3 Wed`). Set a start date in the review
  page's Ship It dialog to export real dates.
